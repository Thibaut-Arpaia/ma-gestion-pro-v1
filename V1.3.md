# Ma Gestion Pro V1.3 - Rapprochement bancaire

## Fonctionnement

Ouvrir le dossier de test. Sur PC, le tableau Rapprochement apparait directement. Choisir le mois ou les dates de debut et de fin. Les filtres Toutes, Entrees, Sorties et A pointer ne changent pas le solde calcule.

Pour chaque operation retrouvee sur le releve, indiquer la date reelle bancaire puis cocher Pointee. Le solde pointe est le solde initial plus les recettes pointees moins les depenses pointees jusqu'a la date de fin. Les depenses historiques sont exclues pour ne pas les deduire une deuxieme fois. Les anciennes operations non pointees sont signalees dans le compteur, meme hors du filtre du mois.

Saisir le solde bancaire reel a la meme date. L'ecart est banque moins solde pointe. La cloture est possible si l'ecart vaut exactement zero et si toutes les operations saisies jusqu'a cette date sont pointees. Elle protege les montants, dates et pointages. Rouvrir la derniere cloture avant de les modifier. Une modification de montant ou de date hors cloture retire le pointage pour reverifier l'operation.

Les pointages et clotures sont conserves dans les sauvegardes JSON, ainsi que les justificatifs. Les anciens dossiers sont compatibles.

## Publication

Televerser le contenu extrait du ZIP a la racine du depot, sans supprimer les anciens fichiers. Modifier la ligne de copie dans .github/workflows/pages.yml pour publier les nouveaux modules :

```text
cp index.html app.js style.css model.mjs storage.mjs receipts.mjs reconciliation.mjs reconciliation-ui.mjs public/
```

La ligne de tests reste :

```text
node --test tests/*.test.mjs
```

Attendre une action verte puis Ctrl+F5. Le dashboard indique V1.3.

## Verification et limites

15 tests Node passent. Simulation DOM : demarrage complet, navigation, filtres, pointage, cloture, verrouillage, reouverture et corbeille des tickets. Test disque : sauvegarde, restauration et reouverture avec pointages et clotures. Controle visuel navigateur reel non realise dans cet environnement.

Cette version ne comprend pas encore import bancaire, detection de doublons, animation/son de cloture ou synchronisation mobile. Les limites V1.2 sur les pieces jointes restent applicables (5 Mo par piece, 20 Mo pour le JSON complet).
