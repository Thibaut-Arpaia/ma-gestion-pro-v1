# Ma Gestion Pro V4.2 test

Version test préparée le 8 octobre 2026.

## Ajouts fonctionnels

- Onglet dédié TVA / URSSAF : lecture des réserves, détail collecté/déductible/payé et enregistrement guidé des paiements.
- Dépenses récurrentes automatiques : les échéances dues sont créées à l’ouverture du dossier, sans validation mensuelle et sans double création.
- Justificatifs externalisés : les PDF, JPG, PNG et WEBP sont enregistrés dans le dossier physique `justificatifs/`; le JSON conserve le chemin.

## Compatibilité

- Les anciens justificatifs encore intégrés au JSON restent lisibles et sont déplacés dans `justificatifs/` au prochain enregistrement.
- L’export complet réintègre les justificatifs et le fond personnalisé pour rester autonome.
- Les clôtures déjà validées restent protégées.

## Contrôle à effectuer

- Ouvrir le dossier de comptes.
- Vérifier la navigation de tous les onglets.
- Vérifier l’onglet TVA / URSSAF avec un paiement fictif si besoin.
- Ajouter une dépense avec justificatif et contrôler la création du fichier dans `justificatifs/`.
- Créer une dépense récurrente de test, rouvrir le dossier et vérifier qu’elle apparaît une seule fois.
