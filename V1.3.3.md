# V1.3.3 — Navigation et bilans

Ordre : Dashboard, Dépenses, Recettes, Rapprochement, Calculatrice, Réglages & sauvegardes.

Le Dashboard propose une synthèse des recettes TTC, dépenses TTC et trésorerie générée, par mois ou année. Le solde initial ne constitue pas une recette. Les saisies annulées sont exclues, l’historique est inclus. Les saisies futures de la période sont incluses : il s’agit du bilan des saisies.

Le bouton Imprimer / enregistrer en PDF ouvre l’impression du navigateur. Choisir Enregistrer en PDF et vérifier l’aperçu. Le rendu PDF réel dans Opera reste à vérifier sur le PC : les tests d’interface utilisent un DOM simulé.

Validation : 21 tests automatisés passent ; navigation des six onglets, périodes et déclenchement de l’impression vérifiés en interface simulée. Le workflow pages.yml ne change pas.
