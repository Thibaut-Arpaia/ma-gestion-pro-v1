# V1.3.2 — contrôles

En bas du Dashboard, le panneau Contrôles à examiner liste les doublons potentiels existants et les tickets manquants. Les boutons ouvrent directement l'opération concernée. Aucune suppression automatique. Une différence orthographique entre libellés ne constitue pas un doublon détecté.

19 tests passent. Les confirmations doublons, accès aux opérations depuis le panneau, navigation et rapprochement ont été vérifiés en interface DOM simulée. Le rendu en navigateur réel reste à vérifier.

Installation habituelle par téléversement du contenu extrait, sans suppression ; workflow V1.3 inchangé. Attendre Actions vert puis Ctrl+F5.
