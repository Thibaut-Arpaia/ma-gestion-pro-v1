# Ma Gestion Pro V1.2 - Justificatifs

Version d'essai basee sur la V1.1 validee.

## Nouveautes

- Un ticket JPEG, PNG ou PDF lie a chaque depense.
- Telechargement du ticket depuis la liste des depenses.
- Remplacement et retrait avec conservation du ticket dans la corbeille de la depense ; restauration possible.
- Compteur des tickets manquants sur le dashboard. Les paiements de provisions et les depenses marquees "Justificatif non requis" sont exclus.
- Tickets inclus dans les sauvegardes JSON, compatibles avec les anciens dossiers.

## Limites

5 Mo par ticket et 20 Mo pour le fichier comptable complet, pieces et corbeille comprises. Utiliser un dossier d'essai. Cette integration ne comprend pas encore OCR, detection de doublons ou synchronisation mobile. Les pieces d'une depense supprimee restent dans les donnees et sauvegardes.

## Publication GitHub

Extraire le ZIP. Televerser son contenu a la racine du depot existant, sans dossier parent et sans supprimer les fichiers existants. Le module receipts.mjs doit etre present. Remplacer aussi .github/workflows/pages.yml : il publie ce nouveau module et execute tous les tests.

Si le televersement refuse le dossier .github, ouvrir .github/workflows/pages.yml dans GitHub et remplacer les deux lignes concernees :

```yaml
          node --test tests/*.test.mjs
```

```yaml
          cp index.html app.js style.css model.mjs storage.mjs receipts.mjs public/
```

Attendre le succes dans Actions, puis actualiser le logiciel avec Ctrl+F5. Le dashboard doit afficher V1.2.
