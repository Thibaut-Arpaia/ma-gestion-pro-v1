# V1.4.4 — Audit des échéances futures

Anomalie confirmée en V1.4.3 : le solde suivi excluait les opérations futures, mais les réserves annuelles TVA/URSSAF les incluaient. Cela faussait le disponible du jour, notamment par déduction anticipée de TVA ou de paiements fiscaux.

Correction : tous les indicateurs financiers du Dashboard utilisent la même date limite, aujourd’hui selon la date locale du PC. Les opérations datées d’aujourd’hui sont incluses ; celles des jours suivants sont exclues. Le bilan et les listes continuent d’inclure les saisies futures. Les taux validés, les règles du point de départ et le format des comptes restent identiques.

Vérification : 29 tests Node réussis, dont 3 nouveaux scénarios couvrant récurrences, abonnement avec TVA, paiements TVA/URSSAF, virement personnel, recettes futures, année suivante, date du jour, modification, annulation et conservation JSON. Les tests existants de sauvegarde/restauration et rapprochement passent. Aucun essai visuel PC réalisé ici.

Contrôle PC proposé : dans Test3, noter solde, réserves et disponible ; créer une échéance après aujourd’hui avec TVA ; vérifier que ces quatre indicateurs restent identiques et que l’échéance figure dans Dépenses et Bilan. Annuler seulement cette nouvelle ligne d’essai si nécessaire.
